## Overview

This directory contains the complete reproducible analysis pipeline for the manuscript:

> **Genetic Composition of South Asian Populations in the Context of
> Neighboring West and Central Asian Groups**

figures, and tables in the manuscript from raw input data.

## Script Descriptions

### Script 01 — Bash QC Pipeline
**File:** `01_quality_control_pipeline.sh`
**Language:** Bash shell
**Tools required:** PLINK v1.9, SAMtools >= 1.12, BCFtools >= 1.12

Performs:
- VCF to PLINK binary format conversion
- Multi-cohort dataset merging with strand flip resolution
- Quality control filtering (SNP missingness, sample missingness, MAF, HWE)
- Pairwise IBS distance matrix computation

**Run:**
```bash
chmod +x 01_quality_control_pipeline.sh
./01_quality_control_pipeline.sh
```

**QC parameters used:**
| Parameter | Value | Meaning |
|-----------|-------|---------|
| `--geno`  | 0.05  | Remove SNPs with >5% missing data |
| `--mind`  | 0.10  | Remove samples with >10% missing data |
| `--maf`   | 0.01  | Remove SNPs with MAF < 1% |
| `--hwe`   | 1e-6  | Remove SNPs violating Hardy-Weinberg |

---

### Script 02 — Python Analysis and Figures
**File:** `02_analysis_and_figures.py`
**Language:** Python 3.12
**Dependencies:** numpy, pandas, scipy, scikit-learn, matplotlib, seaborn, openpyxl, xlsxwriter

Performs:
- Multidimensional Scaling (MDS) from IBS distance matrix
- Population-level pairwise distance computation
- Hierarchical clustering (average linkage)
- Figure 1: MDS scatter (all individuals)
- Figure 2: Distance heatmap
- Figure 3: Hierarchical dendrogram
- Figure 4: Focus panels (Pakistani & Indian groups)
- Figure 5: Geographic map with proximity links
- Figure 6: Within/between region boxplots
- Table 1: Population summary statistics
- Excel export of all raw analysis data

**Install dependencies:**
```bash
pip install numpy pandas scipy scikit-learn matplotlib seaborn openpyxl xlsxwriter
```

**Run:**
```bash
# With default file paths (PCA.mdist and pcAinfo.xlsx in current directory):
python3 02_analysis_and_figures.py

# With explicit paths:
python3 02_analysis_and_figures.py \
    --mdist /path/to/PCA.mdist \
    --meta  /path/to/pcAinfo.xlsx \
    --outdir ./output_figures
```

### Script 03 — R Visualization and Statistics
**File:** `03_R_visualization.R`
**Language:** R >= 4.2
**Dependencies:** tidyverse, ggplot2, ggrepel, readxl, pheatmap, ggdendro, RColorBrewer, gridExtra

Performs:
- ggplot2 MDS scatter plots (PDF, publication ready)
- pheatmap distance heatmap (PDF)
- ggdendro hierarchical dendrogram (PDF)
- Focus panels with ggrepel labels
- ggplot2 boxplots
- One-way ANOVA and Tukey HSD post-hoc tests on regional distance distributions
- Summary statistics table (CSV)

**Install dependencies (run once in R):**
```r
install.packages(c(
  "tidyverse", "ggrepel", "readxl", "pheatmap",
  "ggdendro", "RColorBrewer", "gridExtra"
))
```

**Run:**
```bash
# From command line:
Rscript 03_R_visualization.R

# Or from R console:
source("03_R_visualization.R")
```

> Note: Script 03 requires the CSV outputs from Script 02 as input
> (`mds_coordinates.csv` and `group_distances.csv`).

## Input Data Description

### PCA.mdist
PLINK identity-by-state (IBS) distance matrix output.
- Format: plain text, whitespace-delimited, N × N
- Dimensions: 2,434 × 2,434
- Values: IBS genetic distance between individuals (0 = identical; higher = more distant)
- Diagonal: 0 (each individual compared to itself)
- Generated by: `plink --distance ibs`

### pcAinfo.xlsx
Sample metadata Excel file with the following columns:

| Column     | Description                          |
|------------|--------------------------------------|
| FIID       | Family/sample numeric ID             |
| IID        | Individual ID string                 |
| GROUP      | Population group (24 unique groups)  |
| LABELS     | Ethnic subgroup label                |
| REFERENCE  | Source publication reference         |
| N          | Sample size for that ethnic group    |
| LATITUDES  | Geographic latitude of sampling site |
| LONGITUDES | Geographic longitude                 |
| COUNTRY    | Country of origin                    |
